# Server Performance Stats

A simple Bash script to monitor and analyze basic Linux server performance statistics.

## Project URL

https://roadmap.sh/projects/server-stats

## Features

- Total CPU usage
- Total memory usage (used, free, and percentage)
- Total disk usage (used, free, and percentage)
- Top 5 processes by CPU usage
- Top 5 processes by memory usage
- System information (OS, hostname, and kernel)
- System uptime and load average
- Logged-in users

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```

**2. Make the script executable**

```bash
chmod +x server-stats.sh
```

**3. Execute the script**

```bash
./server-stats.sh
```

## Technologies Used

- Bash scripting
- Linux
- Standard Linux utilities (`ps`, `free`, `df`, `awk`)
